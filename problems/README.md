## Approach

Each problem file contains:
1. **Context** – A short real-world scenario.
2. **Requirements** – What classes, fields, and methods are needed.
3. **Expected Output** – Sample output to target.
4. **Hints** – Guidance on which OOP concepts to apply.

Create your solutions inside a sub-folder named `problem-NN-<name>/`.
